# OLS 面板改进在 YUB 中的对应关系

YUB 继续使用 Nginx、PHP-FPM、FastCGI 缓存及 YUB Optimizer。共享页面和交互按 OLS 的改进同步，运行环境配置按 YUB 的实际服务实现。

| 区域 | YUB 中的位置和行为 |
| --- | --- |
| 导航 | 概览、站点与数据、运维与安全、系统四组；网站维护总览归入网站管理；保留日间/夜间主题 |
| 网站详情 | 概览与运行、缓存与性能、安全与维护、网站日志；定时 WordPress 任务在对应网站中设置 |
| 面板设置 | 常规账户、更新、安装包、备份、操作日志分区；更新失败显示原因；日志支持搜索与筛选 |
| 软件管理 | 保留 Nginx/PHP-FPM 的服务、版本、自启动状态；推荐参数按需查看，不覆盖手动输入；开发工具为可选安装 |
| VPS 网页 | 系统信息、DNS、双栈优先级、Swap、连接队列、清理与维护；管理员已有配置不会静默覆盖 |
| VPS 终端 | `b` / `B` 打开管理菜单；分区菜单、状态与操作反馈；卸载移除命令后退出旧菜单 |
| 安全 | 安全事件与安全设置分开；端口策略、SSH 端口变更、预览及连接确认沿用 YUB 实现 |
| 其他页面 | 告警筛选、文件保护状态、诊断入口、日志空状态、帮助和 WordPress 维护刷新反馈 |

不迁入 OLS 专属的 LSPHP 安装与切换、LiteSpeed Cache 或 WebAdmin 7080 配置。YUB 的 Nginx 自定义配置、FastCGI、站点迁移和 Optimizer 设置继续保留。

网页更新需要实际安装包含这些模板和 CSS 的面板发布包；只刷新浏览器或只修改 GitHub README 不会更新服务器上的面板。
